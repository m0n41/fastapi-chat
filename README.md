# Рядом — небольшой чат

Веб-чат с регистрацией, входом в аккаунт и обменом сообщениями в реальном времени. Интерфейс на русском языке; серверная часть написана на FastAPI, данные хранятся в PostgreSQL.

## Что умеет

- Регистрация и вход с паролем.
- Просмотр и отправка сообщений после входа.
- Обновление чата в реальном времени через WebSocket.
- Проверка подключения к базе данных: `/health/db`.
- Документация API: `/docs`.

## Запуск локально

Нужны Python и запущенный PostgreSQL. В корне проекта выполните команды в PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и укажите адрес своей базы в `DATABASE_URL` и отдельную базу для тестов в `TEST_DATABASE_URL`. Замените `JWT_SECRET_KEY` на случайное значение. Например, его можно получить командой:

```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Основную базу и тестовую нужно создать в PostgreSQL заранее. Имя тестовой базы должно оканчиваться на `_test`, например `fastapi_chat_test`.

После настройки окружения примените миграции и запустите приложение:

```powershell
python -m alembic upgrade head
python -m uvicorn app.main:app --reload
```

## Тесты

Запускаются командой:

```powershell
pytest
```

Тесты работают с базой из `TEST_DATABASE_URL` и при подготовке удаляют и создают заново её схему `public`. Используйте только отдельную тестовую базу: её имя должно оканчиваться на `_test`. Не направляйте `TEST_DATABASE_URL` на базу с нужными данными.

## Перед публикацией

Файл `.env` и виртуальное окружение не предназначены для Git. Для настройки оставлен `.env.example` с примерами значений — настоящие пароли и ключи в него добавлять не нужно.

Это проект для локальной разработки; перед размещением в открытом доступе или использованием в production настройте HTTPS и безопасные cookie, а также проверьте параметры развёртывания.
